# Proyecto Turbidez

Proyecto en Python para el procesamiento y análisis de imágenes utilizando OpenCV, enfocado en el análisis de turbidez en muestras de agua.

## 📁 Estructura del Proyecto

```text
Proyecto_Turbidez/
│
├── imagenes/               # Muestras e imágenes de prueba (ej. agua.jpg)
├── src/                    # Código fuente del proyecto
│   └── primer_opencv.py    # Scripts de análisis y procesamiento con OpenCV
├── .gitignore              # Archivos y carpetas ignorados por Git
├── README.md               # Documentación del proyecto
└── requirements.txt        # Dependencias de Python
```

## 🚀 Requisitos e Instalación

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/ybcbryan/Proyecto_Turbidez.git
   cd Proyecto_Turbidez
   ```

2. **Crear y activar un entorno virtual:**
   - En Windows:
     ```bash
     python -m venv .venv
     .venv\Scripts\activate
     ```

3. **Instalar dependencias:**
   ```bash
   pip install -r requirements.txt
   ```

## 💻 Ejecución

Para ejecutar el script de procesamiento básico de imágenes:
```bash
python src/primer_opencv.py
```
